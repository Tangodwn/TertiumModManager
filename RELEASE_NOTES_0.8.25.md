# Tertium Mod Manager v0.8.25 — Illustrated Tab Banners

This release replaces the schematic placeholder tab graphics with packaged illustrated artwork.

- Deployment: subdued hive-city scene.
- Mod Control: Ogryn-inspired heavy-logistics scene.
- Recovery & Crash Guard: Arbites-inspired containment scene.
- Machine Settings & Tools: Mechanicus-inspired console scene.
- Artwork is bundled inside the Windows build and loaded from a single optimized sprite.
- Code-drawn motifs remain only as a fallback if the artwork asset is unavailable.

- Replaced the Windows executable, installer, Start Menu, and desktop shortcut icon with the Tertium **T** badge.
