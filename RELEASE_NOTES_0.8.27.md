# Tertium Mod Manager v0.8.27 — Professional Tab Split

This release continues the launcher polish by separating configuration from maintenance.

- Added a dedicated **Settings** tab with its own illustrated banner.
- Added a dedicated **Tools & Diagnostics** tab with its own illustrated banner.
- Settings now contains interface mode, Darktide path, Nexus configuration, Tertium updates, and product notes.
- Tools now contains health checks, diagnostic ZIP creation, loader repair, Nexus framework links, and installed-mod adoption.
- Simple Mode hides the Tools & Diagnostics tab to keep the default interface focused.
- Advanced Mode restores Tools & Diagnostics ahead of Settings.
- Uses the previously packaged five-panel artwork sprite: Deployment, Mods, Recovery, Tools, and Settings.
