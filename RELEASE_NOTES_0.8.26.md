# Tertium Mod Manager v0.8.26 — Tertium T Shortcut Icon

This release makes the Tertium **T** badge the explicit Windows shortcut icon.

- Desktop shortcut now points directly to the packaged Tertium T icon.
- Start Menu shortcut now points directly to the same icon.
- Executable and installer continue using the Tertium T icon.
- Illustrated tab artwork from v0.8.25 remains unchanged.
