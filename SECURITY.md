# Security

Please do not post API keys, authentication tokens, personal file paths, or other secrets in public issues.

For reproducible problems, prefer Tertium's diagnostic export after reviewing the archive for information you do not want to share.

Security-sensitive reports should be kept private until a safe disclosure path is established for the public project.

Tertium should never bypass Nexus account restrictions, Darktide authentication, anti-cheat, or platform security controls.
