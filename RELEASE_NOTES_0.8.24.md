# Tertium Mod Manager v0.8.24 — Themed Tab Banners

This release applies the next professional visual pass to Tertium.

## Themed tab banners

Tertium now gives each main workflow a distinct but restrained visual identity while keeping controls readable and uncluttered.

- **Deployment:** subdued hive-city skyline and deployment-craft motif.
- **Mod Control:** Ogryn-inspired heavy logistics silhouette and supply-crate motif.
- **Recovery & Crash Guard:** Arbites-inspired containment shield and enforcement motif.
- **Machine Settings & Tools:** Mechanicus-inspired cog, cabling and console motif.
- Banners are code-rendered and intentionally low-detail to avoid overwhelming the launcher UI.
- Existing card, border, button and status styling remains consistent across tabs.

The design target remains: professional launcher first, grimdark atmosphere second.
