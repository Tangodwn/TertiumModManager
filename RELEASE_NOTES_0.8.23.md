# Tertium Mod Manager v0.8.23 — Hybrid Visual Refresh

This release applies the first visual polish pass to Tertium while keeping the current lightweight Tk/ttk runtime.

## Visual refresh

- Added outlined panel and card styles for clearer hierarchy.
- Added stronger active-tab styling.
- Added a new code-rendered Tertium shield/hex brand mark in the header.
- Added a framed treatment around the main Tertium artwork.
- Added accent framing to deployment/status areas.
- Added dedicated warning styling around Crash Guard.
- Added accent styling around Official Darktide Updates and Interface panels.
- Added a visible border around the Mods list.
- Standardized several major panels onto the new card treatment.

The direction is a hybrid of clean launcher layout and grimdark/industrial accents without introducing new runtime dependencies.
